# Frontend React Engineer | Assessment

## Overview

Build a responsive Flight Search Engine inspired by Google Flights. Apply your own design taste and UX improvements to make it modern and intuitive.

**API**: Amadeus Self-Service API (Test environment)

## Requirements

### Core Features

- [ ] **Search & Results**: Inputs for Origin, Destination, Dates, etc. with a clear list of flight results
- [ ] **Live Price Graph**: Visual graph (Recharts, D3, or similar) showing price trends that updates in real-time as users apply filters
- [ ] **Complex Filtering**: Simultaneous filters (Stops + Price + Airline) that update both the flight list and price graph instantly
- [ ] **Responsive Design**: Fully functional layouts for both mobile and desktop

### Deliverables

1. **GitHub Repository**: Clean, well-structured code
2. **Live Hosted Link**: Accessible to anyone (Vercel, Netlify, etc.)
3. **Loom Demo (3-4 mins)**: Brief walkthrough explaining implementation and decision making

**Timeline**: 4 days (max 16 work hours)
